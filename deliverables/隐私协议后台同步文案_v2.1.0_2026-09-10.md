# 隐私协议后台同步文案 v2.1.0（2026-09-10 修正版）

> 用法：把 `deliverables/隐私协议_后台粘贴文案.txt` 全文复制 → 粘贴到
> 小程序后台「设置 → 服务内容声明 → 用户隐私保护指引」编辑框。
>
> 页内文案：`subpackages/detail/privacy/privacy.wxml`（version 2.1.1 / updatedAt 2026-09-10）
> 用 `npm run privacy:check` 自动校验「生成文案 ↔ 页内」一致（防手抄漂移）。
>
> ⚠️ **正确理解「一致性」（2026-09-10 纠正）**：微信后台用的是**平台标准模板**（固定板块：
> 引导语 / 开发者处理的信息 / 用户权益 / 开发者对信息的存储 / **信息的使用规则** /
> 信息对外提供 / 联系方式 / 日期），与本页自定义章节结构**不可能逐字一致**。
> 此前「必须字节一致、审核逐字比对」的说法**有误**，已纠正。
> 平台真正校验的是：**声明的信息类型与用途 是否与实际隐私接口调用一致**（提审时自动比对）。
> `privacy:check` 的作用是防止**本仓库内部**（页内 ↔ 生成的粘贴文案）漂移，而非对齐平台模板。

## 本次修正了什么（v2.0.0 → v2.1.0）

提审前合规核查发现 v2.0.0 有 **3 处表述与实际代码行为不符**，属不实陈述风险，已全部修正：

| # | v2.0.0 原文（错误） | 实际情况（代码证据） | v2.1.0 修正 |
|---|---|---|---|
| 1 | 第三条：「所有第三方 API 调用均由小程序直接发起（**不经过自有服务器**）」 | `cloudProxy.enabled=true` + `supabase.enabled=true`，请求经微信云函数 `aggregation` / Supabase Edge Function 代理与缓存 | 改为「可能由开发者自有的云服务代为转发或缓存」 |
| 2 | 第二条：「**开启「赛前通知」后**，以下数据将同步至云端」 | `app.js:95` `auth.ensureLogin()` 在 **onLaunch 无条件**执行 `wx.login` → `wechat-auth` EF，OpenID 启动即获取 | 改为「小程序启动时经微信登录接口获取」，并按数据分别说明上传时机 |
| 3 | 第六条：「**开启「赛前通知」时**，小程序通过微信官方登录接口获取您的微信 OpenID」 | 同上，与开关无关 | 改为「启动时获取」，并分述关注列表/订阅状态的上传时机 |
| 4 | 第三条：数据源仅列 4 个 | 实际新增 `dota.haglund.dev` 兜底源 | 补列 haglund.dev |
| 5 | 第七条：「**开启「赛前通知」的用户的**上述数据存储于 Supabase」 | 与修正后的第二条矛盾（OpenID 无条件上传） | 改为「第二条所述上传数据」 |

**上传时机（修正后的准确描述）**：

| 数据 | 时机 | 代码位置 |
|---|---|---|
| OpenID + 业务 JWT | 小程序启动（无条件） | `app.js:95` → `utils/auth.js` ensureOpenId |
| 关注战队列表 + 提醒策略 | 关注页操作时 | `pages/follow/follow.js:309` syncProfile |
| 订阅授权状态 | 开启赛前通知后 | `utils/subscribe.js` syncSubStatus |

## 正文（复制此段）

> ⚠️ **不要手抄正文**——正文由脚本从 WXML 单点生成，手抄必然漂移
> （v2.0.0 就是这么积累出 3 处不实表述的）。

**直接复制这个文件：**

     deliverables/隐私协议_后台粘贴文案.txt

重新生成 / 校验一致性：

     npm run privacy:out      # 从 wxml 重新生成粘贴文案
     npm run privacy:check    # 校验页内 ↔ 粘贴文案一致（不一致退出码 1，并指出差异行）

脚本：`scripts/sync/extract-privacy-text.js`

## 后台「隐私接口声明」勾选核对

按实际代码行为核对，应声明：

| 收集项 | 是否声明 | 用途填写建议 |
|---|---|---|
| 微信 OpenID | ✅ 必须 | 账号标识、跨设备同步、比赛提醒推送 |
| 用户关注列表/提醒设置 | ✅ 必须 | 计算推送内容 |
| 本地缓存 / 搜索历史 | ✅ 已声明 | 离线浏览、降低请求量 |
| 昵称 / 头像 | ❌ 不声明 | 代码未调用 getUserProfile |
| 地理位置 | ❌ 不声明 | 代码未调用 getLocation |
| 手机号 / 通讯录 / 相册 / 麦克风 | ❌ 不声明 | 代码未调用相关接口 |

## 操作步骤

1. 小程序后台 → 「设置 → 服务内容声明 → 用户隐私保护指引」→ 编辑
2. 把 `deliverables/隐私协议_后台粘贴文案.txt` 全文粘入
3. 按上表核对「隐私接口声明」勾选项
4. 提交审核（通常 1-3 个工作日）
5. 提交后跑 `npm run privacy:check` 复核一次未漂移
