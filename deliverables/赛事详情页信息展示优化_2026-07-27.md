# 赛事详情页信息展示优化记录

## 问题背景

1. **The International 2026 等赛事详情页**：KPI Strip（奖金池 / 地点 / 赛制 / 主办方 / 参赛队 / 状态 / 赛期）使用 `grid-template-columns: repeat(auto-fit, minmax(160rpx, 1fr))` + `white-space: nowrap`，在小屏上单元格被压窄，长文本（如 `$1,600,000`、`小组赛+双败淘汰`）被截断显示为 `$1,600,…`、`小组赛+双败…`。
2. **PGL Wallachia Season 9 等赛事详情页**：仅显示「赛期」，缺少奖金池、地点、赛制、主办方、参赛队等模块。原因是这些赛事的 Liquipedia 元数据未返回，且 curation 本地库中缺少对应字段，导致 WXML 里每个 KPI cell 都用 `wx:if` 隐藏了。

## 关键实现说明

### 1. 元数据兜底策略

```js
function mergeMetadataWithFallback(meta, name) {
  const cur = remoteCuration.curatedEventFor(name);
  const fb = cur ? buildCurationFallback(cur) : buildMetadataSkeleton();
  return Object.assign({}, fb, meta || {});
}
```

- Liquipedia / Steam 返回的元数据优先。
- 未返回时，用 `remoteCuration.curatedEventFor(name)` 兜底。
- 再兜底用 `buildMetadataSkeleton()` 保证每个字段都有 key，WXML 不再因 `wx:if` 丢失结构。

### 2. 参赛队伍推导

```js
refreshMetadataDerived() {
  const teamMap = {};
  (this.allMatches || []).forEach((m) => {
    if (m.radiant_team_id != null) teamMap[m.radiant_team_id] = m.radiant_team_name || ('Team ' + m.radiant_team_id);
    if (m.dire_team_id != null) teamMap[m.dire_team_id] = m.dire_team_name || ('Team ' + m.dire_team_id);
  });
  const participantsList = Object.keys(teamMap).map((id) => ({ id: Number(id), name: teamMap[id] }));
  // 补齐 metadata.participants / status / startDate / endDate
}
```

该方法在 `load()`（比赛数据返回后）和 `finalize()`（网络元数据返回后）都会调用，保证最终状态一致。

### 3. KPI Strip 布局

```css
.kpi-strip {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: var(--space-3);
}
.kpi-value {
  word-break: break-word;
  white-space: normal;
  line-height: 1.35;
}
```

- 2 列网格避免小屏被压成 3 列窄条。
- 长文本自动换行，不再截断。
- 赛期单元格 `grid-column: 1 / -1` 独占一行，便于阅读完整日期。
