## 三、🎯 关键：审前必查 3 项

### 1. 「用户隐私保护设置」必须选「采集用户隐私」

提审表单里有这个选项。**选成「未采集隐私」会被平台回收隐私接口调用权限**：

```
{"errMsg": "A:fail appid privacy api banned"}
```

这个错误比漏声明更难恢复（需重新申诉）。我们的确使用了隐私接口（头像/昵称/剪切板），**必须选「采集用户隐私」**。

### 2. 后台隐私指引状态需为「已通过」

若仍是「审核中」，提审会被拦。提交前先看一眼当前状态。

### 3. 真实可用的联系方式

隐私指引里的联系方式（邮箱/微信号）要**真实可用** —— 因为协议里让用户走的「意见反馈」在小程序内未实现（见 `隐私指引勾选核对表_2026-09-10.md` 附带发现 A）。

## 四、⚠️ 已知事项（避免被误判）

| 项 | 说明 |
|---|---|
| 隐私接口在指引通过前可能报错 | 提审/验收时若看到 `api scope is not declared`（errno 112），是**指引仍在审核中**，不是代码问题；指引通过后自动恢复 |
| 无需测试账号 | 小程序全部功能无需登录即可浏览；登录仅在开启「赛前通知」时需要 |
| 数据来源声明 | 使用 OpenDota / STRATZ / Steam / Liquipedia / haglund 公开数据，已在「关于/隐私」页声明非官方 affiliation |
| 版权声明 | 已在隐私协议「十一、版权与商标声明」声明 Valve Fan Art 非商业使用（Steam 订户协议 §3.D） |

## 五、⚠️ 提审前另外两个硬性项（易被忽略）

### 1. 小程序备案（ICP 备案）—— 未完成无法上架

自 2023-09 起新规，小程序须完成**工信部备案**后方可上架。检查路径：

> 后台「设置 → 基本设置 → 小程序备案」

- ☐ 状态为「**已备案**」（非「未备案」/「备案中」/「需补充材料」）
- 备案需要 1-20 个工作日，**如果还没做，这会是最长的等待项**，优先确认

### 2. 服务类目

提审要求服务类目与实际功能匹配。本小程序是「电竞信息查询工具」，建议：

| 建议类目 | 说明 |
|---|---|
| **工具 → 信息查询** | 最贴合（只读查询公开数据，无交易无 UGC） |
| 体育 → 体育资讯 | 备选 |

- ⚠️ 类目选「**游戏**」相关可能触发额外资质要求（如版号/游戏联运），**不要选**
- ☐ 核对当前已选类目与实际功能一致
