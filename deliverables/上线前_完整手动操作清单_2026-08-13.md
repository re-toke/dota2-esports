## 一、云开发控制台（cloud.tencent.com 或开发者工具「云开发」入口）

### 1.1 核对云函数部署状态 ☐

需确认两个云函数均为「已部署」状态（上传一次即覆盖更新；首次上线必须上传）：

| 云函数名 | 用途 | timeout | 触发器 | 源码位置 |
|---|---|---|---|---|
| `aggregation` | 数据聚合代理（OpenDota/Liquipedia/Steam/curation/订阅推送/A/B 实验/赛事发现） | 30s | 每 6 小时刷新缓存 | `cloudfunctions/aggregation/` |
| `cron-discover-tournaments` | 每日凌晨 3 点定时发现新赛事 + 分级同步 | 60s | 每日 03:00 | `cloudfunctions/cron-discover-tournaments/` |

操作：
1. 开发者工具左侧 → 「云开发」→「云函数」
2. 逐个右键 → 「上传并部署：云端安装依赖」（首次）/「上传并部署：所有文件」（更新）
3. 部署完成后状态应为「部署成功」；如失败请查看日志

⚠️ **记忆提醒**：`aggregation/index.js` 与 `utils/liquipedia-parse.js` 是字节级镜像关系，改过客户端解析器必须同步改云函数并重新部署 aggregation。

### 1.2 配置云函数环境变量 ☐

在 `aggregation` 云函数「配置 → 环境变量」中添加：

| 变量名 | 值 | 用途 |
|---|---|---|
| `STEAM_API_KEY` | （你的 Steam Web API key，[申请地址](https://steamcommunity.com/dev/apikey)） | Steam 数据源鉴权 |

申请到 key 后粘贴到此处并「保存」。未配置时 Steam 接口会返回 `NOT_CONFIGURED` 错误，功能降级但不崩溃。

`STRATZ_API_KEY` 当前**不需要配置**（`config.stratz.enabled = false`，因 Cloudflare 拦截已停用）。

### 1.3 核对云函数触发器状态 ☐

进入「云开发 → 云函数 → 触发器」页，确认：
- `aggregation` 有 `cacheRefresh` 触发器（`0 0 */6 * * *`，每 6 小时）
- `cron-discover-tournaments` 有 `dailyDiscover` 触发器（`0 0 3 * * * *`，每日凌晨 3 点）

⚠️ 新部署的云函数触发器有时不会自动同步，需手动添加一次。

### 1.4 核对云数据库集合 ☐

「云开发 → 数据库」确认以下集合存在（首次部署云函数会自动创建，但保险起见核对）：
- `curation_events`（赛事策展数据）
- `admin-logs`（发现/分级日志）
- 其他业务集合由 aggregation 按需创建

## 三、上传体验版 + 真机扫码内测 ☐

### 3.1 上传体验版

1. 开发者工具 → 「上传」→ 填写版本号 `1.1.0` + 备注「上线前内测」
2. 小程序后台 → 「管理 → 版本管理 → 开发版本」→ 将刚上传的版本「选为体验版」
3. 「体验版」旁边二维码 → 用体验版微信扫码

### 3.2 端到端场景验收（建议跑一遍）

| # | 场景 | 验收点 |
|---|---|---|
| 1 | 冷启动首屏 | 加载 < 3s；赛事列表正确加载；分级徽标显示 |
| 2 | 赛事详情页三段切换 | RECENT/LIVE/UPCOMING 段切换流畅；比分/时间显示正确 |
| 3 | 弱网降级 | 开飞行模式 5s 再恢复：应有错误提示 + 重试按钮，不崩溃 |
| 4 | 关注 + 订阅闭环 | 关注赛事 → 弹订阅授权 → 提醒管理页能看到记录 |
| 5 | 分享卡片 | 分享到好友/朋友圈：卡片标题、缩略图、路径正确 |

### 3.3 常见真机问题速查

| 症状 | 可能原因 | 解决 |
|---|---|---|
| 云函数调用全失败 | envId 不匹配 / 未部署 | 核对 §1.1 + `config.cloudProxy.envId` |
| 图片全空 | downloadFile 域名未配 | 核对 §2.1 |
| 订阅授权弹窗失败 | 模板未审 / ID 错 | 核对 §2.3 |
| 隐私协议页打不开 | 后台未同步 | 核对 §2.2 |

## 四、提交审核 ☐

内测通过后：

1. 小程序后台 → 「管理 → 版本管理 → 体验版本」→ 「提交审核」
2. 填写审核信息：
   - 服务类目：选择与「电竞/游戏资讯」最贴近的官方类目
   - 功能页面：首页、赛事详情、关注页
   - 测试账号：如有关注/订阅功能需登录后才能体验，提供测试微信号
3. 提交后通常 1-7 个工作日出审核结果
4. 审核通过后 → 「发布」即上线

### 4.1 审核常见被拒原因预防

| 风险点 | 预防 |
|---|---|
| 隐私协议不一致 | 已在 §2.2 同步，确保字符级一致 |
| 涉及未授权数据源 | OpenDota/Liquipedia 均为公开 API，合规 |
| 类目错配 | 选择「游戏 → 游戏资讯」类目 |
| 测试账号缺失 | 提供可体验关注功能的测试账号 |
| 诱导分享 | 检查分享卡片文案是否中立（当前为中性「DOTA2 赛事详情」） |
